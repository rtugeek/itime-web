# 代码检查与性能优化（2026-09-12）

本次基于工作区当前代码检查并修改，保留原有未提交改动。范围覆盖启动入口、路由、API 会话处理、列表账号过滤、同步及日历更新。未执行服务端权限测试、第三方依赖漏洞库扫描或桌面宿主实机性能测量，不能据此认定项目不存在其他漏洞。

## 已修复

- 列表隐私：生日、待办、倒计时、番茄场景过滤其他账号的本地记录；切换账号时立即清空旧列表。未归属账号的数据仍可见，保持游客数据行为。生日异步加载增加版本校验，避免并发加载追加重复数据。
- 会话竞态：旧登录请求返回业务过期错误或 HTTP 401 时，只能清除发出请求时对应的会话，避免误登出新账号。
- 日志隐私与开销：移除数据库读取、保存及场景加载时整批输出用户数据的日志。
- 短信参数：使用 Axios params 编码，避免特殊字符改变查询参数以及发送字面值 undefined。
- 窗口按钮：最大化按钮改为查询宿主实际状态，修复未定义变量导致点击报错。
- 日历：等待组件实例就绪后填充已有待办；批量更新事件，避免逐条触发重绘；卸载时清理右键监听。
- 同步：兼容旧远端 update_time 时间字段，避免较旧本地记录反向覆盖较新远端数据；快照远端记录建立 Map，减少循环查找。保留上传前重新读取本地数据的并发保护。
- 重复待办：移除对入口注册 isToday 插件的隐式依赖。

## 启动与性能

登录、注册及布局组件改为路由按需加载。颜色选择器及样式移至使用它的组件，取消入口全局注册。

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 主入口 JS | 1695.30 kB | 1388.41 kB |
| 主入口 JS gzip | 547.04 kB | 453.09 kB |

主入口原始体积减少约 18.1%，gzip 减少约 17.2%。这是单个入口 chunk 的构建数据，不是所有首屏资源总量，也不是启动耗时。主入口仍较大，实际效果需在桌面宿主、不同网络和冷缓存环境下测量。
